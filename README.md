# metamorphose

Proyecto de Galería de Fotografías

Este proyecto es una galería de fotografías donde un administrador puede cargar imágenes y clasificarlas en categorías. Los usuarios pueden ver las imágenes sin interactuar con ellas. Se utilizan tecnologías como Next.js, Express, PostgreSQL, Cloudinary, Nodemailer, Sonner, y otras herramientas modernas para el manejo de la interfaz, carga de imágenes y backend.

Frontend

Next.js (versión 15)
Tailwind CSS (para el diseño y estilo de la interfaz)
TypeScript (para mayor robustez en el código)
Sonner (para las notificaciones en pantalla)

Backend

Express (servidor backend)
PostgreSQL (base de datos relacional)
Sequelize (ORM para interactuar con PostgreSQL)
Multer (para la carga de imágenes)
Cloudinary (para el almacenamiento de imágenes)
dotenv (para gestionar las variables de entorno)
body-parser (para manejar el cuerpo de las solicitudes HTTP)
Nodemailer (para el manejo de correos electrónicos)
